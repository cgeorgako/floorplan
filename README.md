# Γεννήτρια Προτάσεων Κατόψεων Κατοικίας

**Τεχνικό Γραφείο Μελετών — Γεωργακόπουλος Χρήστος / Φουντάς Αθανάσιος**
Αμαλιάδα, Π.Ε. Ηλείας · Κλιματική Ζώνη Β

Εφαρμογή σε Python που παράγει **σχηματικές προτάσεις κατόψεων μονοκατοικίας**
από απλά δεδομένα εισόδου, με έξοδο σε **PDF (σε κλίμακα)** και **DXF (R12,
CAD-ready)**. Ο σχεδιασμός ακολουθεί τις βασικές αρχές του αρχείου
[`instructions.md`](instructions.md) (βιοκλιματικός προσανατολισμός, ζώνη
ημέρας/νύχτας, φυσικός φωτισμός & αερισμός κατά Κτιριοδομικό Κανονισμό).

> ⚠ **Σχηματική προμελέτη.** Οι προτάσεις είναι εργαλείο διερεύνησης διάταξης,
> όχι εγκεκριμένη μελέτη. Οι ελάχιστες διαστάσεις χώρων (§2.2 / Παράρτημα Α του
> `instructions.md`) είναι **ΜΗ δεσμευτικές**· δεσμευτικοί είναι μόνο οι έλεγχοι
> ύψους/φωτισμού/αερισμού. Απαιτείται έλεγχος ΣΔ/κάλυψης/ύψους/Δ-δ και πλήρης
> μελέτη πριν την αδειοδότηση.

## Τι ζητά ως δεδομένα

| Δεδομένο | Περιγραφή |
|---|---|
| Μέγιστο περίγραμμα (Α–Δ × Β–Ν) | Διαστάσεις μέγιστου ορθογωνίου εντός του οποίου τοποθετείται η κάτοψη (m) |
| Προσανατολισμός κύριας εισόδου | Β / Ν / Α / Δ |
| Όροφοι | 1 (ισόγειο) ή 2 (διώροφο) |
| Πάχος εξωτερικής / εσωτερικής τοιχοποιίας | m |
| Πλήθος υπνοδωματίων | ≥ 1 |
| Λουτρά / WC | πλήθος του καθενός |
| Οικιακή αποθήκη, βεστιάριο, καθιστικό, σαλόνι, μεγάλη κουζίνα | ναι/όχι |
| Ελάχιστη πλευρά υπνοδωματίου | π.χ. 3,00 m |
| Μέγιστο εμβαδόν **με τους τοίχους** | m² |
| Πλήθος προτάσεων-λύσεων | πόσες κατόψεις να εξαχθούν |
| Σχήμα περιγράμματος | `polygonal` (Γ/L — **προεπιλογή**) ή `rectangular` |

## Κανόνες διάταξης (ενσωματωμένοι)

Πέρα από τις αρχές του `instructions.md`, ο σχεδιασμός τηρεί τους εξής κανόνες:

1. **Ελαχιστοποίηση διαδρόμου** — ο διάδρομος περιορίζεται στο ελάχιστο πλάτος
   και μόνο στη ζώνη νύχτας (στόχος 10–16% της καθαρής επιφάνειας, Α.6.2).
2. **Πολυγωνικό περίγραμμα (Γ/L) ως προεπιλογή** — ορθογώνιο μόνο αν ζητηθεί ρητά
   (`footprint_shape: "rectangular"`).
3. **Χωρίς καμπύλες στο περίγραμμα** — αποκλειστικά ορθογωνισμένες ακμές.
4. **Καθιστικό ↔ Σαλόνι**: λειτουργική επικοινωνία (ανοιχτό πέρασμα).
5. **Σαλόνι ↔ Κουζίνα**: λειτουργική επικοινωνία (ανοιχτό πέρασμα).

Οι κανόνες 4 & 5 υλοποιούνται ως **ανοιχτή, συνεχής ζώνη ημέρας** (καθιστικό–
σαλόνι–κουζίνα σε σειρά, με ανοιχτά περάσματα μεταξύ τους). Το πολυγωνικό (Γ)
εφαρμόζεται στο ισόγειο μονώροφου· σε **διώροφο** το περίγραμμα τηρείται
ορθογώνιο ώστε οι όροφοι να είναι δομικά συνεπείς.

## Τι παράγει

Για κάθε πρόταση:
- **PDF** (A3 οριζόντιο) με την κάτοψη κάθε ορόφου **σε τυποποιημένη κλίμακα**
  (1:50 / 1:100 …), με:
  - **εσωτερικές (καθαρές) και μικτές (με τοίχους) διαστάσεις** κάθε δωματίου,
  - συνολικές εξωτερικές διαστάσεις, **γραμμική κλίμακα**, **βέλος Βορρά**
    (πάντα επάνω), θύρες με φύλλο/τόξο, παράθυρα, υπόμνημα γραφείου,
  - σελίδα **πίνακα χώρων** + **έλεγχο φωτισμού/αερισμού** ανά χώρο (Κ.Κ. αρ. 20/21).
- **DXF R12** (AC1009), με οργανωμένα layers (`WALLS`, `ROOMS`, `OPENINGS`,
  `DIMS`, `TEXT`, `NORTH`, `TITLE`, `OUTLINE`), γεωμετρία `POLYLINE/VERTEX/SEQEND`,
  συντεταγμένες σε **μέτρα, κανόνας 1:1**, ελληνικά κείμενα σε κωδικοσελίδα
  ANSI_1253.
- Ένα ενιαίο PDF (`*_ola.pdf`) με όλες τις προτάσεις μαζί.

Ο **Βορράς είναι πάντα στο επάνω μέρος** (+Y). Ο μακρύς άξονας τοποθετείται
κατά Ανατολή–Δύση όπου το επιτρέπει το περίγραμμα (instructions.md §5.3).

## Εγκατάσταση

```bash
python3 -m pip install -r requirements.txt
```

Μοναδική εξάρτηση: **reportlab** (για το PDF). Το DXF γράφεται χειροκίνητα,
χωρίς εξάρτηση. Για τα ελληνικά στο PDF χρησιμοποιείται η γραμματοσειρά
`assets/DejaVuSans.ttf` (περιλαμβάνεται).

## Χρήση

**Διαδραστικά** (ερωτήσεις στα ελληνικά):

```bash
python -m floorplan_gen
```

**Από αρχείο JSON:**

```bash
python -m floorplan_gen --config examples/example_config.json --out out
```

**Προγραμματιστικά:**

```python
from floorplan_gen import BuildingSpec, Orientation, run

spec = BuildingSpec(
    max_width_ew=13.0, max_length_ns=10.0, entrance=Orientation.S, floors=1,
    ext_wall=0.30, int_wall=0.10, bedrooms=3, baths=1, wcs=1,
    has_storage=True, has_wardrobe=False, has_living=True, has_salon=True,
    has_big_kitchen=True, min_bedroom_side=3.0, max_total_area=130.0,
    num_proposals=3, project_name="Μονοκατοικία Αμαλιάδας",
)
run(spec, outdir="out")
```

### Παράδειγμα εισόδου (JSON)

Βλ. [`examples/example_config.json`](examples/example_config.json). Ο
προσανατολισμός δέχεται `Β/Ν/Α/Δ` ή `N/S/E/W`.

## Πώς δουλεύει η μηχανή διάταξης

1. **Κτιριολογικό πρόγραμμα** ([`program.py`](floorplan_gen/program.py)):
   από τα δεδομένα δημιουργείται λίστα χώρων με επιθυμητά εμβαδά & ελάχιστες
   πλευρές (τιμές Παραρτήματος Α — Neufert/NDSS/NKBA) και ζώνη προσανατολισμού.
2. **Περίγραμμα & ζώνες** ([`layout.py`](floorplan_gen/layout.py)): το κτίριο
   συντίθεται από δύο ορθογώνια «κύτταρα» — μια **πτέρυγα ημέρας** (νότια, πλήρες
   πλάτος) και μια **πτέρυγα νύχτας** (βόρεια). Στο πολυγωνικό (προεπιλογή) η
   πτέρυγα νύχτας είναι στενότερη → **Γ-σχήμα** με εσοχή στη ΒΑ γωνία
   (ορθογωνισμένο περίγραμμα, χωρίς καμπύλες).
3. **Διάταξη**:
   - Ζώνη ημέρας: καθιστικό–σαλόνι–κουζίνα σε **ανοιχτή σειρά** με λειτουργική
     επικοινωνία μεταξύ τους.
   - Ζώνη νύχτας: **βόρεια σειρά υπνοδωματίων** (φυσικός φωτισμός) + **νότια σειρά
     βοηθητικών** (λουτρά/WC/αποθήκη/χωλ/κλίμακα), με **ελάχιστο διάδρομο** ανάμεσα.
   - Τα πλάτη υπολογίζονται ώστε **όλα τα υπνοδωμάτια** να τηρούν την ελάχιστη
     πλευρά· η κάτοψη είναι πλήρως συμπληρωμένη, χωρίς επικαλύψεις.
4. **Παραλλαγές**: κάθε πρόταση παίρνει διαφορετική δομική παραλλαγή (κατοπτρισμός
   Α–Δ, λόγος πτερύγων, πλάτος διαδρόμου) ώστε οι λύσεις να διαφέρουν εμφανώς.
5. **Ανοίγματα**: παράθυρα στους χώρους κύριας χρήσης (προτίμηση Νότος>Ανατ.>
   Βορ.>Δύση), διαμπερής αερισμός, θύρες προς τον διάδρομο, ανοιχτά περάσματα στη
   ζώνη ημέρας, **θύρα εισόδου πάντα στην όψη του ζητούμενου προσανατολισμού**.
6. **Έλεγχος** ([`compliance.py`](floorplan_gen/compliance.py)): άνοιγμα φωτισμού
   ≥10% και ανοιγόμενο αερισμού ≥5% του καθαρού εμβαδού ανά χώρο κύριας χρήσης.

## Περιορισμοί (γνωστοί)

- Οι κατόψεις είναι **σχηματικές**· δεν τοποθετούνται έπιπλα ούτε αναλυτικά
  είδη υγιεινής (τα εμβαδά προκύπτουν από τα εργονομικά δεδομένα).
- Το **πολυγωνικό περίγραμμα** υλοποιείται ως **Γ-σχήμα** (μία εσοχή). Πιο
  σύνθετα σχήματα (Π/Τ) δεν υποστηρίζονται ακόμη.
- Το Γ-σχήμα εφαρμόζεται στο **ισόγειο μονώροφου**· σε **διώροφο** το περίγραμμα
  τηρείται **ορθογώνιο** (δομική συνέπεια ορόφων).
- Σε **πολύ πιεσμένο περίγραμμα** ορισμένοι χώροι ενδέχεται να βγαίνουν κάτω από
  την επιθυμητή ελάχιστη πλευρά — επισημαίνεται ρητά ως προειδοποίηση.
- Δεν γίνεται έλεγχος πολεοδομικών μεγεθών (ΣΔ, κάλυψη, ύψος, Δ-δ, ιδεατό
  στερεό) — αφορούν το οικόπεδο και τη μελέτη, όχι την κάτοψη αυτή καθαυτή.
